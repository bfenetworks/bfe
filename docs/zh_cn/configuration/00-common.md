# 公共类型

以下公共类型在多个配置项中复用，具体配置项的合法性条件中通过「类型名」引用即可。

## 1. 网络端口（Port）

- 类型为整数（Integer）。
- 取值范围为 1-65535（IANA 有效端口范围，RFC 793）。

## 2. 监听地址（ListenAddr）

- 类型为字符串（String）。
- 空字符串表示监听所有地址（即 `0.0.0.0` / `::`）。
- 非空时须为有效的 IPv4/IPv6 地址，或符合 RFC 1123 的主机名。

## 3. 文件路径（FilePath）

- 类型为字符串（String）。
- 未配置时自动回退为对应默认值。
- 支持相对路径（相对于 BFE 配置根目录解析）或绝对路径（以 `/` 开头）。
- 指向的文件须在运行加载时存在且可读。

## 4. 目录路径（DirPath）

- 类型为字符串（String）。
- 未配置时自动回退为对应默认值。
- 支持相对路径（相对于 BFE 配置根目录解析）或绝对路径（以 `/` 开头）。
- 指向的目录须在运行加载时存在且可读。

## 5. 配置文件版本（Version）

- 类型为字符串（String）。
- 通常采用时间戳格式，如 `20190101000000`。
- 用于标识配置文件的版本。

## 6. 主机名（Hostname）

- 类型为字符串（String）。
- 须为符合 RFC 1123 的主机名，或有效的 IPv4/IPv6 地址。
- 主机名总长度不超过 255 字符。
- 每个标签（`.` 分隔）长度不超过 63 字符。
- 标签仅允许大小写字母、数字、连字符（`-`）。
- 标签不得以连字符（`-`）开头或结尾。
- **长度须 ≥ 2 字符**。

## 7. IP 地址（IPAddr）

- 类型为字符串（String）。
- 须为符合 RFC 791 的 IPv4 地址，或符合 RFC 8200 的 IPv6 地址。
- **IPv4**：点分十进制，4 段，每段取值 0-255，如 `192.0.2.1`。
- **IPv6**：8 组 16 位十六进制，组间以 `:` 分隔，支持 `::` 压缩，如 `2001:0db8::1`。

## 8. 权重（Weight）

- 类型为整数（Integer）。
- 非负整数，用于表示权重比例。
- 具体约束依配置项语义而定（例如是否允许为 0、是否要求权重之和大于 0 等）。

## 9. HTTP 状态码模式（HTTPStatusCodePattern）

- 类型为字符串（String）。
- 支持特定状态码（如 `"500"`）或状态码范围（如 `"4xx"`、`"5xx"`）。
- 多个模式之间使用 `|` 连接，如 `"503|4xx"`。

## 10. 动作参数表达式（ActionParam）

部分模块（`mod_rewrite`、`mod_redirect`、`mod_header`）的动作参数支持以 `=`
前缀内嵌表达式，在请求处理阶段按请求上下文求值。参数写法分三种：

| 参数写法 | 含义 |
| -------- | ---- |
| `=expr`  | 表达式，结果必须为字符串。配置加载时编译并做类型检查；编译失败则配置加载失败 |
| `==text` | 转义字面量，表示以 `=` 开头的普通字符串：`==foo` 等价于 `=foo`，`==` 等价于 `=` |
| 其他     | 普通字面量，原样使用（不经过表达式编译） |

运行期约定：

- 表达式参数在配置加载时预编译，请求处理时求值；
- 单个参数求值失败（类型不符、数据源异常等）时按空字符串 `""` 处理并输出
  warn 日志，不影响同一动作的其他参数与其他动作的执行；
- 表达式取数函数在数据缺失时返回零值，不视为错误；
- 该语法与条件表达式引擎模式（`ConditionEngineMode`）无关，任何模式下均生效；
- 具体哪些动作的哪些参数支持表达式，以各模块配置文档为准。

表达式可用的取数函数、内置变量、用户变量与数据源函数，详见
[expr 条件表达式引擎设计](../sys_design/expr_condition_engine.md)。

示例（把请求头设置为客户端 IP）：

```json
{
    "Cmd": "REQ_HEADER_SET",
    "Params": ["X-Bfe-Client-Ip", "=ReqCip()"]
}
```

注意：若存量参数值本身以 `=` 开头，请改写为 `==` 转义。
