# mod_block 全局 IP 黑名单配置

## 配置简介

`ip_blocklist.data` 是 `mod_block` 模块的全局 IP 黑名单配置文件，用于配置全局封禁的 IP 地址或 IP 段。

## 配置描述

每行配置一个或多个 IP 地址；每行可包含一个单独 IP，或一个 IP 段的起始 IP 与结束 IP（以空格分隔）。

| 配置项   | 类型   | 参数含义         | 必填 | 补充描述          | 合法性条件                          |
| -------- | ------ | ---------------- | ---- | ----------------- | ----------------------------------- |
| IP 地址  | String | 单独的 IP 地址   | Y    | 合法的 IPv4 地址  | 类型为 [IPAddr](../00-common.md#7-ip-地址ipaddr) |
| 起始 IP  | String | IP 段的起始地址  | Y    | 与结束 IP 成对配置 | 类型为 [IPAddr](../00-common.md#7-ip-地址ipaddr)；须小于等于结束 IP |
| 结束 IP  | String | IP 段的结束地址  | Y    | 与起始 IP 成对配置 | 类型为 [IPAddr](../00-common.md#7-ip-地址ipaddr)；须大于等于起始 IP |

## 配置示例

```
192.168.1.253 192.168.1.254
192.168.1.250
```
