# TLS Session Ticket Key配置

## 配置简介

session_ticket_key.data配置记录了session ticket key信息。

## 配置描述

| 配置项           | 类型   | 参数含义             | 必填 | 补充描述                                                                                                                                         | 合法性条件                                                               |
| ---------------- | ------ | -------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| Version          | String | 配置文件版本         | Y    | 参见 [Version](../00-common.md#5-配置文件版本version) 类型定义                                                                                      | 类型为 [Version](../00-common.md#5-配置文件版本version)                     |
| SessionTicketKey | String | Session Ticket密钥   | Y    | 96字符十六进制字符串（表示48字节原始密钥），字符仅包含0-9、a-f；也支持直接存放48字节原始密钥的二进制文件（当JSON解析失败时作为回退） | 长度为96的十六进制字符串（0-9, a-f），或为48字节原始密钥的二进制文件 |

## 配置示例

```json
{
    "Version": "20190101000000",
    "SessionTicketKey": "08a0d852ef494143af613ef32d3c39314758885f7108e9ab021d55f422a454f7c9cd5a53978f48fa1063eadcdc06878f"
}
```
