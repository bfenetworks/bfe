# mod_trace

## Introduction

mod_trace enables tracing for requests based on defined rules.

## Configuration

- [mod_trace.conf](../../configuration/mod_trace/mod_trace.conf.md)
- [trace_rule.data](../../configuration/mod_trace/trace_rule.data.md)

## Metrics

| Metric | Description |
| ------ | ----------- |
| START_SPAN_COUNT | Total count of started spans |
| FINISH_SPAN_COUNT | Total count of finished spans |
