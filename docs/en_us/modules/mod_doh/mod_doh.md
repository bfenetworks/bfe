# mod_doh

## Introduction

Module doh supports DNS over HTTPS.

## Module Configuration

For details, see [mod_doh.conf](../../configuration/mod_doh/mod_doh.conf.md).

## Metrics

| Metric | Description |
| ------ | ----------- |
| DOH_REQUEST | Total count of DoH requests |
| DOH_REQUEST_NOT_SECURE | Count of DoH requests not secure |
| FETCH_DNS_ERR | Count of DNS fetch errors |
