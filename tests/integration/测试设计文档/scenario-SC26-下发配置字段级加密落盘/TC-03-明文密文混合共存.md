# TC-03 明文密文混合共存

## 目的

验证灰度中期的混合形态：同一 `token_rule.data` / `cluster_conf.data` 内明文与密文
字段共存时，无 marker 字段直通、有 marker 字段解密，加载成功且行为正确。

对应实现：`TestTC03_MixedPlaintextCiphertextCoexist`（`scenario-SC26-encrypted-config-fields/`）。

## 前置条件

- keyring（keyID=1）已配置。
- `token_rule.data`：`ak-plain`（明文）与 `ak-enc`（密文外层键）共存。
- `cluster_conf.data`：`Keys` 中 `k1`（明文 Key）与 `k2`（密文 Key）共存，
  `Weight` 合计 100。

## 执行步骤

1. 启动 BFE。
2. 分别携带 `ak-plain`、`ak-enc` 发送请求。
3. 多发送若干请求（覆盖多 Key 加权路径）。

## 预期结果

- 启动成功；第 2 步两个 token 均鉴权通过（200）。
- mock 后端收到的 `Authorization` 在 `k1`/`k2` 明文 key 间按权重分布：两条上游
  key 均完成解密、加权选择逻辑不变。

## 清理

- 停止 BFE、关闭 mock 后端。
