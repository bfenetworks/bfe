# TC-01 精确匹配命中

## 用例编号与名称

TC-01 精确匹配命中

## 所属场景

SC20 AI 缓存精确匹配

## 版本声明

- `bfe`：当前源码版本（含 `mod_ai_cache`）

## 测试目的

验证首个请求未命中并回写 Redis，相同问题的第二个请求命中缓存且不再调用上游。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程与嵌入式 Redis。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. 嵌入式 Redis 已启动。
3. mock 后端 `cluster_cache` 已启动，返回 200 与非流式答案 `BFE is a layer-7 load balancer`。
4. 临时 BFE 配置已生成并加载，包含 `mod_ai_cache` 规则：`cacheKeyStrategy=lastQuestion`、`cacheTTL=3600`、`maxBodyBytes=1048576`、`maxValueBytes=1048576`。
5. `ai_route.data` 中 `apikey_ak_cache` 命中 `cache-default`，target 为 `cluster_cache`。
6. `ak_cache` 绑定无限额配额计划（`unlimited_plan`），避免配额耗尽干扰。

## 配置构造

- 缓存规则：

```json
{
    "cond": "default_t()",
    "cacheKeyStrategy": "lastQuestion",
    "cacheTTL": 3600,
    "maxBodyBytes": 1048576,
    "maxValueBytes": 1048576
}
```

## BFE 请求

发送 2 次相同 POST 请求：

| 步骤 | Host | Path | Authorization | Body |
|------|------|------|---------------|------|
| 1 | `cache.example.org` | `/v1/chat/completions` | `Bearer ak_cache` | `{"model":"deepseek-chat","messages":[{"role":"user","content":"what is bfe?"}]}` |
| 2 | `cache.example.org` | `/v1/chat/completions` | `Bearer ak_cache` | 同上 |

## 预期结果

- 第一次请求返回 200，响应体包含上游答案 `BFE is a layer-7 load balancer`。
- Redis 中出现缓存键 `ai_cache:cache_key_id:{question_sha256}`（测试轮询等待，最长 5s）。
- 第二次请求返回 200，响应头 `X-Bfe-Ai-Cache: hit`，响应体包含缓存答案。
- `cluster_cache` mock backend 被命中 1 次。

## 清理

停止 `bfe` 进程、mock 后端与嵌入式 Redis，删除临时目录。
