# TC-04 流式缓存命中

## 用例编号与名称

TC-04 流式缓存命中

## 所属场景

SC20 AI 缓存精确匹配

## 版本声明

- `bfe`：当前源码版本（含 `mod_ai_cache`）

## 测试目的

验证流式（SSE）答案在真实分帧传输下按 chunk 累积回写缓存；相同的流式请求命中时返回一段完整 SSE 序列（含 `data:[DONE]`）。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程与嵌入式 Redis。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. 嵌入式 Redis 已启动。
3. mock 后端 `cluster_cache` 以 `SSEEvents` 模式启动，逐帧 flush 3 个 chunk：role-only 首包、`BFE is`、` a gateway`。
4. 临时 BFE 配置已生成并加载，包含 `mod_ai_cache` 规则（同 TC-01）。

## BFE 请求

发送 2 次相同流式 POST 请求：

| 步骤 | Host | Path | Authorization | Body |
|------|------|------|---------------|------|
| 1 | `cache.example.org` | `/v1/chat/completions` | `Bearer ak_cache` | `{"model":"deepseek-chat","stream":true,"messages":[{"role":"user","content":"what is bfe?"}]}` |
| 2 | 同上 | 同上 | 同上 | 同上 |

## 预期结果

- 第一次请求返回 200，透传全部 SSE chunk；上游 SSE 被解析，答案 `BFE is a gateway` 回写 Redis（轮询确认）。
- 第二次请求返回 200，`Content-Type: text/event-stream`；响应体为一段完整 SSE：单帧 `data:` 包含 `BFE is a gateway`，并以 `data:[DONE]` 结尾（末尾空行结束事件）。
- `cluster_cache` mock backend 被命中 1 次。

## 清理

停止 `bfe` 进程、mock 后端与嵌入式 Redis，删除临时目录。
