# TC-09 命中不扣配额

## 用例编号与名称

TC-09 命中不扣配额

## 所属场景

SC20 AI 缓存精确匹配

## 版本声明

- `bfe`：当前源码版本（含 `mod_ai_cache`）

## 测试目的

验证配额/计费协同：缓存命中时 `mod_ai_token_auth` 跳过 token 扣减；缓存未命中时按实际 usage 扣减。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程与嵌入式 Redis。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. 嵌入式 Redis 已启动。
3. mock 后端 `cluster_cache` 已启动，返回 200 与非流式答案（`usage` 为 `prompt_tokens=10, completion_tokens=8`）。
4. 临时 BFE 配置已生成并加载：
   - `mod_ai_cache` 规则（同 TC-01）；
   - token 规则绑定有限配额计划：`plan_total`，`unit=total_token`，`quota=1000`，`redis_key=quota:plan_total`。
5. 测试前置将 `quota:plan_total` 设为 1000。

## BFE 请求

| 步骤 | Authorization | Body |
|------|---------------|------|
| 1 | `Bearer ak_cache` | `{"model":"deepseek-chat","messages":[{"role":"user","content":"what is bfe?"}]}` |
| 2 | `Bearer ak_cache` | 同上（命中缓存） |
| 3 | `Bearer ak_cache` | `{"model":"deepseek-chat","messages":[{"role":"user","content":"something else?"}]}` |

## 预期结果

- 步骤 1（miss）：返回 200；扣减 10+8=18，配额余额 1000 → 982（异步扣减，轮询断言）。
- 步骤 2（hit）：返回 200 且 `X-Bfe-Ai-Cache: hit`；配额余额保持 982（命中跳过扣减）。
- 步骤 3（新问题 miss）：返回 200；配额余额 982 → 964。

## 清理

停止 `bfe` 进程、mock 后端与嵌入式 Redis，删除临时目录。
