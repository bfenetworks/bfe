# TC-09 客户端残留凭证头被清理

## 用例编号与名称

TC-09 客户端残留凭证头被清理

## 所属场景

SC06 Claude 协议支持

## 版本声明

- `bfe`：当前源码版本（2026-10-22 issue #1447 起）

## 测试目的

验证 issue #1447：网关接管上游凭证时（`selectedKey.Key != ""`），**出站请求只携带本次注入的那一个凭证头**，客户端带来的其它凭证头（`Authorization` / `x-api-key` / `x-goog-api-key`）被删除。

上游对这几个头的优先级是 **provider 私有且方向相反**的：kimi 认 `x-api-key`（优先于 `Authorization`），bailian 认 `Authorization`（且不回落）。修复前网关只"覆盖"自己那一个头、不删除残留头，客户端同时带两个凭证头时上游会用**客户端的**凭证鉴权 → 401 → 被误判为该 Key 鉴权失败并写入惩罚键（生产现场：kimi 集群 2 把 Key 全灭、流量静默降级）。本用例覆盖三种臂：

| 臂 | 上游行为 | 客户端头 | 关注点 |
|---|---|---|---|
| A（生产故障复现） | kimi 型：`x-api-key` 非空即 401 | `Authorization` + `x-api-key` | 残留头被删除后请求成功，且 Key 不再被判死 |
| B（对称格） | bailian 型：`Authorization` 不等于注入凭证即 401 | `Authorization` + `x-api-key` | 清理不破坏"认 Authorization"的上游 |
| C（anthropic 风格） | 常规 200 | `x-api-key` + `x-goog-api-key` | 非注入的 `x-goog-api-key` 同样被删除 |

## 运行模式

单组件模式：仅启动真实 `bfe` 进程。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. mock 后端 `cluster_both_protocols` 已启动，`ModelProtocols = ["openai", "anthropic"]`，`Keys = [both-openai-key, both-anthropic-key]`。
3. 各臂在 BFE 启动后给该 mock 后端安装"上游凭证偏好"行为（`MockBackend.ResponseFunc`：按收到的凭证头返回 401 / 200），不新增集群配置。

## 配置构造

- `cluster_both_protocols.AIConf`：`ModelProtocols: ["openai", "anthropic"]`；`Keys`：`both-openai-key`、`both-anthropic-key`（Weight 各 50）。

## BFE 请求

臂 A / 臂 B：

| 字段 | 值 |
|------|-----|
| Host | `both.example.org` |
| Path | `/v1/chat/completions` |
| Authorization | `Bearer ak_user_a` |
| x-api-key | `ak_user_a` |
| Body | `{"model":"gpt-4"}` |

臂 C：

| 字段 | 值 |
|------|-----|
| Host | `both.example.org` |
| Path | `/v1/messages` |
| x-api-key | `ak_user_a` |
| x-goog-api-key | `ak_user_a` |
| Body | `{"model":"claude-3-5-sonnet","messages":[{"role":"user","content":"hi"}]}` |

## 预期结果

臂 A（kimi 型上游）：

1. 响应 200；
2. 上游收到的 `x-api-key` 为空、`Authorization` 为集群 Key 之一；
3. `bfe.log` 不含 `auth failed (401), dead`；
4. **对照断言（防假阳性）**：直接向 mock 端口发送一条携带 `x-api-key` 的请求**必须得到 401**，证明该 mock 确实处于"会被残留头打死"的模式。

臂 B（bailian 型上游）：

5. 响应 200（mock 仅在 `Authorization` 等于注入的集群 Key 时返回 200）；
6. 上游 `x-api-key` 为空。

臂 C（anthropic 风格 + 残留 gemini 头）：

7. 响应 200；
8. 上游 `x-api-key` 为集群 Key 之一、`Authorization` 为空、`x-goog-api-key` 为空。

## 清理

停止 `bfe` 进程、mock 后端，删除临时目录。
