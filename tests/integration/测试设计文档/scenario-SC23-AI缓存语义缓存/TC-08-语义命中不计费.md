# TC-08 语义命中不计费

## 用例编号与名称

TC-08 语义命中不计费

## 所属场景

SC23 AI 缓存语义缓存

## 版本声明

- `bfe`：当前源码版本（含 `mod_ai_cache` 语义缓存二期）

## 测试目的

验证计费协同：语义命中与精确命中一样跳过 token 配额扣减（复用 `AiCacheHit` 机制），miss 按响应 usage 实际扣减。

## 运行模式

单组件模式：真实 `bfe` 进程 + 内存 Redis + 进程内 embedding mock / Chroma mock。

## 前置条件

1. 同 TC-01 前置条件 1-3。
2. token 规则改用**有限配额**计划：`plan_total`，单位 `total_token`，配额 1000，Redis 键 `quota:plan_total`；两个 API Key 均绑定该计划。
3. 测试前向内存 Redis 写入配额初值 1000。
4. mock 后端非流式答案 usage 为 `prompt_tokens=10, completion_tokens=8, total_tokens=18`（单次 miss 扣 18）。

## 配置构造

- 缓存规则：同 TC-01（`Semantic` 块 + `enableSemanticCache=true`）。
- 配额计划：

```json
{
    "Id": "plan_total",
    "Unlimited": false,
    "PassNoQuota": false,
    "RedisKey": "quota:plan_total",
    "ExpiredTime": -1,
    "Quota": 1000,
    "Unit": "total_token"
}
```

## BFE 请求

| 步骤 | Host | Path | Authorization | Body |
|------|------|------|---------------|------|
| 1 | `cache.example.org` | `/v1/chat/completions` | `Bearer ak_cache` | `{"model":"deepseek-chat","messages":[{"role":"user","content":"what is bfe?"}]}` |
| 2 | 同上 | 同上 | 同上 | `{"model":"deepseek-chat","messages":[{"role":"user","content":"could you introduce bfe to me please?"}]}` |
| 3 | 同上 | 同上 | 同上 | `{"model":"deepseek-chat","messages":[{"role":"user","content":"how to cook rice at home?"}]}` |

## 预期结果

- 第 1 步（miss）：轮询（最长 5s）确认配额 1000 → **982**（扣 18）；轮询确认 Chroma `upsert=1`。
- 第 2 步（语义命中）：响应头 `X-Bfe-Ai-Cache: hit_semantic`；等待 500ms 后配额仍为 **982**（**语义命中零扣减**）。
- 第 3 步（另一问题 miss）：轮询确认配额 982 → **964**（再扣 18）。
- 配额扣减为异步行为，一律轮询断言而非瞬时读取。

## 清理

停止 `bfe` 进程、mock 后端、embedding mock、Chroma mock 与内存 Redis，删除临时目录。
