# TC-04 错误驱动即时重试（cell is not serving）

## 目的

验证可重试错误的单请求路径：主 EPP 对首个消息返回 `Unavailable / cell is not serving` 时，BFE 不等健康检查状态机，直接在同请求的下一地址（备）上重试并成功。

对应实现：`TestTC04_ErrorDrivenRetry`。

## 前置条件

- 两个 mock EPP；主 EPP `SetRequestError(Unavailable, "cell is not serving")`。
- `EPPCheck`：`FailThreshold=3`、正常周期——确保行为差异来自错误驱动重试而非健康检查 failover。

## 执行步骤

1. 发送请求（标记串 `hello-epp-tc04`）。
2. 断言响应成功且为 sim echo。
3. 断言主、备各收到 1 个流（主收到首消息后报错，备完成完整处理）。

## 预期结果

- 响应 200，body 含 `hello-epp-tc04`。
- `epp[0].StreamCount() == 1` 且 `epp[1].StreamCount() == 1`。
- 说明：`epp_calls_total` 记录请求级最终结局（`ok`），主上的 draining 尝试只体现在 BFE 日志，不做指标断言。

## 清理
