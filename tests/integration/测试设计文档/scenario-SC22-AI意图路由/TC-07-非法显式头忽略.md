# TC-07 非法显式头忽略

## 用例编号与名称

TC-07 非法显式头忽略

## 所属场景

SC22 AI 意图路由

## 版本声明

- `bfe`：当前源码版本（含 `mod_ai_intent`）

## 测试目的

验证非法显式意图头被忽略：请求带 `X-AI-Intent: task_type=bogus`（bogus 不是 task_type 的合法选项），该条目被丢弃并回落模型分类；body prompt「写文档」被判为 doc_writing@0.95 + medium@0.90 → 规则 3 → `cluster_flash`。

## 运行模式

单组件模式：真实 `bfe` 进程 + mock 上游后端（`cluster_flash` / `cluster_kimi`）+ mock 决策服务（测试进程内 `httptest.Server`）。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. mock 决策服务已启动，`Calls()` 计数清零，「写文档」脚本返回 doc_writing@0.95 + complexity score=1（medium，probabilities.medium=0.90）。
3. mock 后端 `cluster_flash`、`cluster_kimi` 已启动，`Hits()` 计数清零。
4. 临时 BFE 配置已生成并加载（同 TC-01）。
5. `ak_intent` 绑定无限额配额计划。

## 配置构造

- 路由表 `apikey_ak_intent`（场景说明 §4.3）：规则 3 → `cluster_flash`。

## BFE 请求

| 步骤 | Host | Path | Authorization | Headers | Body |
|------|------|------|---------------|---------|------|
| 1 | `intent.example.org` | `/v1/chat/completions` | `Bearer ak_intent` | `X-AI-Intent: task_type=bogus` | `{"model":"deepseek-chat","messages":[{"role":"user","content":"帮我写文档，说明这个模块的用法"}]}` |

## 预期结果

- 请求返回 200，响应体含 `from cluster_flash` → 命中规则 3。
- `cluster_flash` `Hits()=1`，`cluster_kimi` `Hits()=0`。
- mock 决策服务 `Calls()=1`：非法头部条目被忽略后回落模型分类（`ReqHeader=0`）。

## 清理

停止 `bfe` 进程、mock 后端与 mock 决策服务，删除临时目录。
