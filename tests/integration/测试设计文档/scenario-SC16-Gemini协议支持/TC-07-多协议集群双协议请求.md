# TC-07 多协议集群双协议请求

## 用例编号与名称

TC-07 多协议集群双协议请求

## 所属场景

SC16 Gemini 协议支持

## 版本声明

- `bfe`：当前源码版本（2026-09-09 gemini 协议支持起）

## 测试目的

验证 `ModelProtocols=["openai","gemini"]` 的集群可同时处理两种协议请求，认证头按各自协议正确注入：openai 请求上游收到 `Authorization: Bearer <cluster key>`；gemini 请求上游收到 `x-goog-api-key: <cluster key>` 且无 `Authorization`。

## 运行模式

单组件模式：真实 `bfe` 进程 + 进程内 miniredis。

## 前置条件

`cluster_both_protocols` 双协议、双 key（`sk-both-openai-key` / `goog-both-gemini-key`，权重各 50）。

## BFE 请求

1. POST `/v1/chat/completions`，Host `both.example.org`，`Authorization: Bearer ak_user_a`。
2. POST `/v1beta/models/gemini-2.5-flash:generateContent`，Host `both.example.org`，`x-goog-api-key: ak_user_a`。

## 预期结果

1. 两次响应均为 200；`cluster_both_protocols` 命中 2 次。
2. 第一次请求上游 `Authorization` 为 Bearer cluster key；第二次请求上游 `x-goog-api-key` 为 cluster key 且 `Authorization` 为空。
