# TC-06 缺省值归一（旧控制面报文）

## 目的

验证向后兼容：`KeyPolicy` 不含两个惩罚时长字段（旧控制面导出 / 老配置）时，JSON 解码为 `0`，加载期 `AIKeyPolicyCheck` 补默认值 60 / 300，**不会**把 `0` 传给 `Setex`（Redis 语义下 `expire=0` 等于永不过期）。

## 前置条件

- `cluster_penalty_ttl` 配 2 把 Key；
- `SessionAffinity=true`、`SessionAffinityPenaltyEnable=true`；
- `SessionAffinityPenaltyTTL429=0`、`SessionAffinityPenaltyTTLAuth=0`（等价于字段缺省）；
- miniredis 为空。

## 请求构造

同 TC-01。

## 后端响应

| 子用例 | mock 后端行为 |
|--------|----------------|
| auth 档 | 任意请求返回 `401` |
| 429 档 | 任意请求返回 `429` |

## 执行步骤

1. 启动 BFE（两字段为 0），发送 1 条请求（401 档），读取惩罚键 TTL；
2. 以 429 档启动新环境（两字段为 0），发送 1 条请求并读取 TTL。

## 预期结果

- 两个惩罚键的 TTL 均 **> 0**（不出现「无过期」的键）；
- 401 档 TTL 为 **300s**，429 档 TTL 为 **60s**；
- 无 `Setex` 相关告警日志。

## 清理

同 TC-01。
