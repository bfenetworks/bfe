# TC-02 显式配置生效

## 目的

验证集群级配置生效：`SessionAffinityPenaltyTTLAuth=120` 时 401 惩罚键 TTL 为 120 秒；`SessionAffinityPenaltyTTL429=30` 时 429 惩罚键 TTL 为 30 秒。

## 前置条件

- `cluster_penalty_ttl` 配 2 把 Key（Weight 50/50），`SessionAffinity=true`、`SessionAffinityPenaltyEnable=true`；
- `SessionAffinityPenaltyTTL429=30`、`SessionAffinityPenaltyTTLAuth=120`；
- miniredis 为空。

## 请求构造

同 TC-01。

## 后端响应

| 子用例 | mock 后端行为 |
|--------|----------------|
| auth 档 | 任意请求返回 `401` |
| 429 档 | 任意请求返回 `429` |

## 执行步骤

1. 启动 BFE，`penalty_ttl_auth=120`；
2. 发送 1 条请求；
3. 读取惩罚键 TTL；
4. 以 `penalty_ttl_429=30` 启动新环境，发送 1 条请求并读取 TTL。

## 预期结果

- auth 档：两个惩罚键 TTL 均等于 **120s**；
- 429 档：两个惩罚键 TTL 均等于 **30s**；
- BFE 日志出现 `penalty_ttl=120` / `penalty_ttl=30`（`ai key [...] auth failed` / `rate limited (429)` 行）。

## 清理

同 TC-01。
