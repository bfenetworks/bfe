# TC-05 子网不允许

## 用例编号与名称

TC-05 子网不允许

## 所属场景

SC39 鉴权错误矩阵与 Token 配额计划

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证来源 IP 不在 Key 的 `subnet` 内时返回 `SUBNET_NOT_ALLOWED`。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程；AI 后端为进程内 mock，Redis 为进程内 miniredis。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. 嵌入式 Redis 已启动；mock 后端 `cluster_auth` 已启动，返回 150 token 的 usage。
3. `bfe.conf` 中 `EnableAiGateway=true`，加载 `mod_ai_route`、`mod_ai_token_auth`、`mod_body_process`、`mod_access_pb3`。
4. `ai_route.data` 中 `ak_auth` 命中 `cluster_auth`。

## 配置构造

- `ak_auth`：`subnet=10.0.0.0/8`（请求来源为 127.0.0.1）。
- 配额余额充足，确保拒绝原因来自子网检查而不是配额。

## BFE 请求

| 步骤 | Host | Path | Authorization | Body | 说明 |
|------|------|------|---------------|------|------|
| 1 | auth.example.org | /v1/chat/completions | Bearer ak_auth | {"model":"gpt-4"} | 来源 IP 不在子网 |

## 预期结果

- HTTP 403，`error.code=SUBNET_NOT_ALLOWED`。
