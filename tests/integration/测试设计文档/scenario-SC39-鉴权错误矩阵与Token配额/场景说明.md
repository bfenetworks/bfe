# SC39 鉴权错误矩阵与 Token 配额计划

## 1. 场景背景与目的

`mod_ai_token_auth` 是 2025-08-24 AI 网关底座的一部分，负责 API Key 鉴权与配额计划扣减。已有场景覆盖了 RMB 配额计费（SC03）与访问日志中的 `ai_auth_reject_reason`（SC05），但**鉴权错误矩阵**（无 Key / 无效 Key / 禁用 / 过期 / 子网）与 **Token 维度配额计划的生命周期**（过期、余额耗尽、Redis 故障、`Unlimited`/`PassNoQuota`、多计划）没有系统覆盖。

本场景验证：

- 五类鉴权失败的 HTTP 状态码、`error.code`、`details` 字段与访问日志 `ai_auth_reject_reason`；
- `Unit=total_token` 配额计划的正常扣减（按真实 usage）与余额耗尽拒绝；
- 配额计划过期（`QUOTA_EXPIRED`）与余额不足（`QUOTA_EXHAUSTED`）的区分；
- 配额 Redis 故障（`INTERNAL_QUOTA_ERROR`）与余额不足的区分；
- `Unlimited` 与 `PassNoQuota` 两条放行路径；
- 多配额计划：全部扣减、任一不足即拒；
- 鉴权规则 `Cond` 不匹配时跳过鉴权；
- `ProductRulePath` 缺省时按模块默认路径加载（`596c484b` 回归）。

## 2. 运行模式

- **单组件模式**：仅启动真实 `bfe` 进程；
- AI 后端为进程内 `httptest` mock，Redis 为进程内 miniredis；
- 不涉及 `ai-gateway-api` 与 `conf-agent`。

## 3. 涉及的 BFE 配置文件

| 文件 | 说明 |
|------|------|
| `bfe.conf` | `EnableAiGateway=true`，加载 `mod_ai_route`、`mod_ai_token_auth`、`mod_body_process`、`mod_access_pb3` |
| `mod_ai_route/ai_route.data` | `ak_auth`（及测试用第二/第三 Key）命中 `cluster_auth` |
| `mod_ai_token_auth/token_rule.data` | 运行时按用例生成：`QuotaPlans` / `Tokens` / `Config` 三段 |
| `mod_ai_token_auth/mod_ai_token_auth.conf` | 默认 `ProductRulePath`；TC-13 将其清空以验证默认路径 |
| `mod_body_process/body_process.data` | 默认规则，解析响应 usage 以驱动 Token 扣减 |
| `cluster_conf/gslb.data` | `cluster_auth` 单子集群 |
| `cluster_conf/cluster_table.data` / `cluster_conf.data` | 运行时根据 mock 后端与 `AIConf` 生成 |

## 4. 测试 Cluster 与配置

- `cluster_auth.AIConf`：单 provider key（`sk-sc39-1`），`MaxRetries=0`；
- mock 后端固定返回 `{"usage":{"prompt_tokens":100,"completion_tokens":50,"total_tokens":150}}`，即单次请求扣减 150 Token；
- Redis 初始余额由用例通过 `SetQuota` 写入（Key 形如 `quota:token`）。

## 5. 错误码与 HTTP 映射（断言依据）

| 场景 | `error.code` | HTTP | 额外字段 |
|------|--------------|------|----------|
| 无 api-key | `NO_API_KEY` | 401 | `ai_auth_reject_reason=NO_API_KEY` |
| Key 不存在 | `INVALID_API_KEY` | 401 | `details.api_key` |
| Key 禁用 | `KEY_DISABLED` | 403 | `details.key_id`、`ai_auth_reject_reason` |
| Key 过期 | `KEY_EXPIRED` | 403 | `details.key_id` |
| 子网不允许 | `SUBNET_NOT_ALLOWED` | 403 | — |
| 配额不足 | `QUOTA_EXHAUSTED` | 429 | `details.limit_type=api_key_quota`、`details.quota_plan_id`、`ai_auth_reject_quota_plans` |
| 配额计划过期 | `QUOTA_EXPIRED` | 429 | `details.quota_plan_id`、`ai_auth_reject_quota_plans` |
| 配额 Redis 故障 | `INTERNAL_QUOTA_ERROR` | 500 | `details.quota_plan_id` |
