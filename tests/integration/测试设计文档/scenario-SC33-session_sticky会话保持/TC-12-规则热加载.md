# TC-12 规则热加载

## 用例编号与名称

TC-12 规则热加载

## 所属场景

SC33 session_sticky 会话保持

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证 `/reload/mod_session_sticky` 后新规则生效。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程；后端与审计服务均为进程内 mock。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. `cluster_sticky` 内启动 2 个 mock 后端（同一子集群，权重相同），用于区分 sticky 是否命中。
3. `bfe.conf`：`EnableAiGateway=false`，`Modules = mod_session_sticky`。
4. 需要 Redis 的用例启动 miniredis，并由 harness 将 `[redis] Bns` 重写为测试实例。

## 配置构造

- 初始规则为 Cookie 模式。
- 通过 `/reload/mod_session_sticky` 加载空规则列表。

## BFE 请求

| 步骤 | Host | Path | 关键设置 | 说明 |
|------|------|------|----------|------|
| 1 | sticky.example.org | /v1/chat/completions | reload 前 | 期望 Set-Cookie |
| 2 | sticky.example.org | /v1/chat/completions | reload 后 | 期望无 Set-Cookie |

## 预期结果

- 步骤 1：返回 `Set-Cookie`。
- 步骤 2：无 `Set-Cookie`。
