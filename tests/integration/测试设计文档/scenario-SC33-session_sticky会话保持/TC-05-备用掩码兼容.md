# TC-05 备用掩码兼容

## 用例编号与名称

TC-05 备用掩码兼容

## 所属场景

SC33 session_sticky 会话保持

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证主掩码切换后，旧会话仍可通过 StandbyMaskCode 解密。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程；后端与审计服务均为进程内 mock。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. `cluster_sticky` 内启动 2 个 mock 后端（同一子集群，权重相同），用于区分 sticky 是否命中。
3. `bfe.conf`：`EnableAiGateway=false`，`Modules = mod_session_sticky`。
4. 需要 Redis 的用例启动 miniredis，并由 harness 将 `[redis] Bns` 重写为测试实例。

## 配置构造

- 规则：`MaskCode=newmask`、`StandbyMaskCode=oldmask`。
- 测试用 `oldmask` 构造指向 backend A 的 Cookie。

## BFE 请求

| 步骤 | Host | Path | 关键设置 | 说明 |
|------|------|------|----------|------|
| 1 | sticky.example.org | /v1/chat/completions | 旧掩码 Cookie | 指向 backend A |

## 预期结果

- HTTP 200；backend A 命中 1 次，backend B 0 次。

## 关联实现

- 测试代码：同场景目录下 `*_test.go` 的 `TestTC05_*` 函数
