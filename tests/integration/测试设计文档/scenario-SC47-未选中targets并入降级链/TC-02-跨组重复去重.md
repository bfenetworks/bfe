# TC-02 跨组重复去重

## 目的

验证 `targets=[A/x:100]` + `fallbacks=[A/x, B/y]` 这类**跨组重复**的合法配置（ai-gateway-api `00-common.md` §6 明确允许）在并入降级链后被去重：同一 `(cluster_name, model)` 在一次请求内只被尝试一次。

## 前置条件

- BFE 启动，路由规则 `target-fb-dedup`：`targets=[{cluster_ta, model "m", weight 100}]`，`fallbacks=[{cluster_ta, "m"}, {cluster_fc, "m"}]`；
- mock：`cluster_ta` 返回 500 + 错误体；`cluster_fc` 返回 200 + `{"cluster":"fc"}`；
- 两个 cluster 初始命中数均为 0。

## 请求构造

| 字段 | 值 |
|------|-----|
| Method | POST |
| Host | `target-fb.example.org` |
| Path | `/v1/chat/completions` |
| Header | `Authorization: Bearer ak_target_fb`、`Content-Type: application/json` |
| Body | `{"model":"gpt-4"}` |

连续发送 10 条同构请求。

## 后端响应

| cluster | 行为 |
|---------|------|
| cluster_ta | 500 + `{"error":"ta unavailable"}` |
| cluster_fc | 200 + `{"cluster":"fc"}` |

## 执行步骤

1. 启动 BFE 与两个 mock 后端；
2. 连续发送 10 条请求；
3. 收集每条响应的 HTTP 状态码与响应体；
4. 读取两个 mock 的 `Hits()`。

## 预期结果

- 全部 10 条响应均为 200，响应体为 `{"cluster":"fc"}`；
- `cluster_ta.Hits() == 10`：每条请求中 `cluster_ta` **恰好被尝试 1 次**——首次作为选中 target，fallback 中的重复项被去重不再尝试（旧行为下会尝试 2 次，该断言可区分新旧行为）；
- `cluster_fc.Hits() == 10`：去重后链为 `ta → fc`，fc 逐条兜底。

## 清理

测试结束时关闭 BFE 与 mock 后端（`testEnv.Close()`）。
