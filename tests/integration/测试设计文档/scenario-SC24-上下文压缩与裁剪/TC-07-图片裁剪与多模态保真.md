# TC-07 图片裁剪与多模态保真

## 用例编号与名称

TC-07 图片裁剪与多模态保真（keepLatestImages=2 / 0）

## 所属场景

SC24 上下文压缩与裁剪

## 版本声明

- `bfe`：当前源码版本（含 `mod_ai_context`）

## 测试目的

验证 L1.5 内联图片裁剪：历史 user 消息中 4 张内联 `image_url`（data URI）只保留最近 2 张，被裁的替换为占位文本 `[Earlier image removed to fit context window]`；content parts 数组结构合法（type 字段完整、数组非空）；受保护的最后一条 user 消息（含其多模态 parts）一张图不动。第二个 case 验证 `keepLatestImages=0` 按设计（4.2：0=不裁图）关闭图片裁剪。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程。

## 前置条件

1. 同 TC-01，但使用独立 `context_rule.data`（`mode=conservative`，`keepLatestImages=2`；第二个 case 为 `keepLatestImages=0`），不影响共享 testdata 样例。

## 配置构造

- `maxContextTokens=200, reserveTokens=50`（budget 150）；`imageTokenEstimate=100`（估算器对内联 data URI 图按固定估值，4+1 张图 ≈ 500 token，远超触发线 120）。
- body：msg0 user 含 4 张内联图 + text part；msg1 assistant（600 字符 `reasoning_content`，**是唯一 assistant**——L2 对最后一条 assistant 保留 thinking）；msg2 user（最后一条，受保护）含 1 张内联图 + text `current question`。

## BFE 请求

| 步骤 | Host | Path | Authorization | Body |
|------|------|------|---------------|------|
| 1 | `ctx.example.org` | `/v1/chat/completions` | `Bearer ak_ctx` | imageBody（keepLatestImages=2 规则） |
| 2 | 同上 | 同上 | 同上 | imageBody（keepLatestImages=0 规则，独立 env） |

## 预期结果

- 步骤 1：
  - 200，响应头精确值断言 `mode=conservative`；
  - 后端 msg0：内联图恰剩 2 张、占位文本恰 2 个、parts 数组长度 5 且每个 part 带 `type` 字段；
  - 后端 msg2（受保护的最后 user）：内联图恰 1 张、0 占位、与原始 body **逐字节一致**；
  - 访问日志 `status=trim`、`mode=conservative`。
- 步骤 2：`keepLatestImages=0` 不裁图——msg0 4 张图全保留、0 占位、与原始 body 逐字节一致；响应头仍标注（thinking 被 L2 裁剪，触发线仍达）。
