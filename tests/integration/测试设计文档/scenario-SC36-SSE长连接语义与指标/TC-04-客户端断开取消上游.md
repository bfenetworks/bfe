# TC-04 客户端断开取消上游

## 用例编号与名称

TC-04 客户端断开取消上游

## 所属场景

SC36 SSE 长连接语义与指标

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证 cancelOnClientClose：客户端在流中途断开后，BFE 立即取消上游读取并释放活跃计数。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程；后端为进程内 mock（HTTP/HTTPS/SSE 按用例配置）。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. mock 后端 `cluster_sse` 已启动；Redis（miniredis）已启动用于 token 规则加载。
3. `bfe.conf`：`EnableAiGateway=true`，加载 `mod_ai_route`、`mod_ai_token_auth`。
4. `ai_route.data` 中 `ak_auth` 命中 `cluster_sse`；`token_rule.data` 声明不限量 Key `ak_auth`。
5. `cluster_sse.ClusterBasic.TimeoutWriteClient=300`（毫秒）。

## 配置构造

- mock 后端：发送首帧后由 `SSEHold` 持有流；尾帧标记为不应送达。
- 请求声明 `Accept: text/event-stream`。

## BFE 请求

| 步骤 | Host | Path | 关键请求设置 | 说明 |
|------|------|------|--------------|------|
| 1 | sse.example.org | /v1/chat/completions | `Accept: text/event-stream` | 读取首帧后关闭客户端连接 |

## 预期结果

- 客户端在 backend 仍持有流（hold 未释放）时，`proxy_state.SSE_REQ_ACTIVE` 回到 0。
