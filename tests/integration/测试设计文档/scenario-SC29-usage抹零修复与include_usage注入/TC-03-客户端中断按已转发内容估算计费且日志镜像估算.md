# TC-03 客户端中断按已转发内容估算计费且日志镜像估算

## 目的

验证 issue #1478（计费臂）+ issue #1398（估算镜像）在客户端中断场景下的行为：OpenAI 流式请求被客户端 RST 中断、无 final usage 时，BFE 按**已转发内容**估算计费（issue #1352 的"未交付内容不计费"实质保留），并把估算镜像进共享 `TokenUsage`——访问日志如实记录 `in / out / total = in+out`，`ai_usage_source=aborted`。零扣费臂（`EstimateToken=false`）由 SC12 TC-04 覆盖。

对应实现：`TestTC03_ClientAbortKeepsLogViewZeroDeduction`（`scenario-SC29-usage-snapshot-billing/sc29_usage_snapshot_billing_test.go`）。

## 前置条件

- BFE 已启动并加载 `cluster_usage_snapshot`，`EstimateToken = true`、`InjectStreamUsage = true`，加载 `mod_access_pb3`。
- Redis 中 `quota:plan_rmb` 余额预置为 `10000000000`。
- mock 后端 SSE 模式：发送 content chunk 后阻塞在 `SSEHold`；中断由 `cancelOnClientClose` 感知（CloseWatcher 关闭上游 body），`SSETrailing` 1MB 帧仅用于覆盖写错误路径。

## 请求构造

| 字段 | 值 |
|------|-----|
| Method | `POST` |
| Host | `usage-billing.example.org` |
| Path | `/v1/chat/completions` |
| Header | `Authorization: Bearer ak_user_a` |
| Header | `Content-Type: application/json` |
| Body | `{"model":"gpt-4","stream":true,"messages":[{"role":"user","content":"hi"}]}` |
| 连接 | 裸 TCP；收到 content chunk 后 `SO_LINGER=0` RST 中断 |

## 后端响应（SSE）

```
data: {"id":"chatcmpl-1","choices":[{"delta":{"content":"hello"}}]}

（阻塞，直至客户端中断后释放）

data: {"id":"chatcmpl-1","choices":[{"delta":{"content":"<1MB 填充>"}}]}
```

## 执行步骤

1. 启动 BFE、mock 后端与内存 Redis，预置余额。
2. 客户端通过裸 TCP 发送请求，读取 SSE 数据直至出现 content chunk。
3. 客户端设置 `SO_LINGER=0` 后关闭连接（TCP RST）。
4. 等待请求收尾（扣减同步发生在 finish handler，sleep 1.5s 后查 Redis）。
5. 停止 BFE，`common.ParseAccessLogAfterStop(logDir)` 解析 pb3 日志。

## 预期结果

- **按已转发内容扣费**（逐事件整数除法）：
  - `promptEst = len(请求体)/4 = 18`（鉴权期播种）
  - `completionEst = len(content chunk)/4 + len(注入错误事件帧)/4 = 16 + 33 = 49`
    （注入帧为 issue #1474 的 `streamTruncationInjector` 在中断关闭上游 body 时补发的错误事件，计入读取路径估算——与 TC-07/08 口径一致）
  - `remaining = 10000000000 − (18×300 + 49×900) = 9999950500`
- pb3 日志：`ai_input_tokens=18`、`ai_output_tokens=49`、`ai_total_tokens=67`（估算镜像，issue #1398 语义）、`ai_usage_source=aborted`。
- 修复前行为（issue #1352 时期）：零扣费，日志 `in=18 / out=0 / total=0`（分项保留但 total 断链）。

## 与其他用例的关系

- 计费口径（配额级）由 SC12 TC-01 覆盖；零扣费臂信号由 SC12 TC-04 覆盖；
- 上游中途断流的同类口径见 TC-07（issue #1474）。

## 清理

- 停止 BFE、关闭 mock 后端与 Redis。
