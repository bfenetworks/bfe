# TC-04 无重定向行为不退化

## 用例编号与名称

TC-04 无重定向行为不退化（目标模型等于请求体原始模型）

## 所属场景

SC18 Key 模型白名单按目标模型校验

## 版本声明

- `bfe`：issue #1387 修复起

## 测试目的

验证无 ModelMapping、无路由 Model 覆盖的场景（`cluster_plain`）下，目标模型等于请求体原始模型，`allow_models` 含原始模型名时放行，后端收到的 model 保持 `glm-5.2-abc` 不变——即修复后无重定向的现行语义不退化。

## 运行模式

单组件模式：真实 `bfe` 进程 + 进程内 miniredis（计费断言）。

## 前置条件

1. 同 TC-01 环境，唯一差异为 token `ak_user_a` 配置 `allow_models="glm-5.2-abc"`。
2. `cluster_plain` 无 ModelMapping，返回 200 与 `usage.total_tokens=15` 的 openai 非流式响应体。

## BFE 请求

POST `http://<bfe>/v1/chat/completions`，Host `plain.example.org`：

| 字段 | 值 |
|------|----|
| Authorization | Bearer ak_user_a |
| Content-Type | application/json |
| body | `{"model":"glm-5.2-abc","messages":[{"role":"user","content":"hello"}]}` |

## 目标模型计算

1. 路由目标 Model 覆盖：空，保持 `ClientModel=glm-5.2-abc`；
2. 无 StripPrefix、无 ModelMapping；
3. 目标模型 = `glm-5.2-abc` ∈ allow_models → 放行，body model 不变。

## 预期结果

1. 响应 200，响应体为后端透传（含 `"total_tokens":15`）；
2. `cluster_plain` 命中 1 次，收到的请求体 model 为 `glm-5.2-abc`（未被改写）；
3. 异步扣款完成后（sleep 500ms），`quota:plan_token` 余额 = 1000000 - 15。
