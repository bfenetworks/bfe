# TC-09 规则条件与热加载

## 用例编号与名称

TC-09 规则条件与热加载

## 所属场景

SC35 body_process 流式处理与内容审查

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证规则 Cond 匹配与 `/reload/mod_body_process` 热加载。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程；后端与审计服务均为进程内 mock。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. mock 后端 `cluster_audit` 与审计服务（`/text-filter`、`/text-replace`）已启动。
3. `bfe.conf`：`EnableAiGateway=true`，加载 `mod_ai_token_auth`、`mod_ai_route`、`mod_body_process`。
4. `ai_route.data` 中 `ak_audit` 命中 `cluster_audit`；`token_rule.data` 声明不限量 Key。

## 配置构造

- 初始规则 Cond：`req_path_prefix_in("/api", true)`。
- reload 前将规则 Cond 改为 `default_t()`。

## BFE 请求

| 步骤 | Host | Path | 关键设置 | 说明 |
|------|------|------|----------|------|
| 1 | audit.example.org | /v1/chat/completions | Cond 不匹配 | 期望 0 次审计 |
| 2 | audit.example.org | /api/chat | Cond 匹配 | 期望 1 次审计 |
| 3 | audit.example.org | /v1/chat/completions | reload 后 | 期望审计累计 2 次 |

## 预期结果

- 步骤 1：审计 0 次；步骤 2：审计 1 次；步骤 3：审计累计 2 次。
