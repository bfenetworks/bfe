# TC-01 请求体审查放行

## 用例编号与名称

TC-01 请求体审查放行

## 所属场景

SC35 body_process 流式处理与内容审查

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证请求体审查放行时转发内容语义不变、以 chunked 发送。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程；后端与审计服务均为进程内 mock。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. mock 后端 `cluster_audit` 与审计服务（`/text-filter`、`/text-replace`）已启动。
3. `bfe.conf`：`EnableAiGateway=true`，加载 `mod_ai_token_auth`、`mod_ai_route`、`mod_body_process`。
4. `ai_route.data` 中 `ak_audit` 命中 `cluster_audit`；`token_rule.data` 声明不限量 Key。

## 配置构造

- 规则 `RequestProcess`：`Dec=json`、`Proc=[{textfilter, [审计 URL]}]`。
- 审计返回 `RiskLevel=PASS`。

## BFE 请求

| 步骤 | Host | Path | 关键设置 | 说明 |
|------|------|------|----------|------|
| 1 | audit.example.org | /v1/chat/completions | JSON body | 审查放行 |

## 预期结果

- HTTP 200；后端收到语义相同的 JSON；`ContentLength=-1`、`Transfer-Encoding: chunked`。
- 审计 `/text-filter` 调用 1 次且 `txt` 为完整请求体。
