# TC-09 镜像错误分类

## 用例编号与名称

TC-09 镜像错误分类

## 所属场景

SC21 流量镜像（mod_traffic_mirror）

## 测试目的

验证镜像目标返回非 200 + OpenAI 错误 JSON 时，读空过程解析 `error.type` / `error.code` 并计入 `error_type_total`——"有没有报错"要细到 `rate_limit_exceeded` 而非只有 502。同时验证镜像失败不影响主链路。

## 运行模式

单组件模式。

## 前置条件

1. `cluster_primary`：200 正常应答。
2. `cluster_mirror`：每次命中返回 429，Body：`{"error":{"message":"too many requests","type":"rate_limit_exceeded","code":"rpm_limit"}}`。
3. 镜像规则：`cond=default_t()`、`mirrorCluster=cluster_mirror`、`percentage=100`。

## BFE 请求

POST `mirror.example.org/v1/chat/completions` 1 次。

## 预期结果

- 客户端返回 200（主上游应答，镜像失败对客户端完全不可见）。
- `cluster_mirror` 命中 1 次。
- 指标（轮询等待）：
  - `resp_status_total{cluster="cluster_mirror",status="429"} = 1`
  - `error_type_total{cluster="cluster_mirror",type="rate_limit_exceeded",code="rpm_limit"} = 1`
  - `fail_total{cluster="cluster_mirror"} = 0`（收到了 429 响应并完成读空，不算发送失败）

## 清理

停止 `bfe` 进程、mock 后端与嵌入式 Redis。
