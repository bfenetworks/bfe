# TC-15 计费隔离

## 用例编号与名称

TC-15 计费隔离

## 所属场景

SC21 流量镜像（mod_traffic_mirror）

## 测试目的

验证镜像流量是网关内部 fire-and-forget 子请求：不经过 `mod_ai_token_auth` 配额扣减。主请求按上游 usage 扣减（prompt 10 + completion 8 = 18），镜像请求产生了真实推理 usage（prompt 99 + completion 77）但**不产生任何扣减**。

## 运行模式

单组件模式（含嵌入式 Redis 配额计划 `plan_total`，总额度 1000）。

## 前置条件

1. `ak_mirror` 绑定限额配额计划（`quota:plan_total`，Quota=1000，单位 total_token）。
2. `cluster_primary`：200 + usage `{"prompt_tokens":10,"completion_tokens":8}`。
3. `cluster_mirror`：200 + usage `{"prompt_tokens":99,"completion_tokens":77}`（镜像推理真实发生）。
4. 镜像规则：`cond=default_t()`、`mirrorCluster=cluster_mirror`、`percentage=100`。

## BFE 请求

POST `mirror.example.org/v1/chat/completions` 1 次。

## 预期结果

- 客户端返回 200。
- Redis 配额余额：扣减后 = 982（仅主请求 18 tokens；轮询等待异步扣减完成）。
- 镜像完成后（`req_labeled_total{cluster="cluster_mirror"} = 1`，且 `tokens_total` 记录 prompt=99/completion=77——证明镜像推理确实发生），再等待 500ms，配额余额**仍为 982**：镜像 usage 未产生任何扣减。
- `cluster_primary` / `cluster_mirror` 各命中 1 次。

## 清理

停止 `bfe` 进程、mock 后端与嵌入式 Redis。
