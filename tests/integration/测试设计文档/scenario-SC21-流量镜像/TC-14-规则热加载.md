# TC-14 规则热加载

## 用例编号与名称

TC-14 规则热加载

## 所属场景

SC21 流量镜像（mod_traffic_mirror）

## 测试目的

验证 `mirror_rule.data` 通过 monitor 端口热加载后行为即时切换（`/reload/mod_traffic_mirror?path=`），返回 `文件名=Version` 供 conf-agent 对账。

## 运行模式

单组件模式。

## 前置条件

1. 初版镜像规则：`Version=1.0`、`cond=default_t()`、`mirrorCluster=cluster_mirror`、`percentage=0`。
2. 热加载版镜像规则：`Version=2.0`、其余同上但 `percentage=100`。

## BFE 请求

1. 发送 1 次请求（p=0，不镜像）。
2. 重写 `mirror_rule.data` 为 2.0（p=100），调用 `GET /reload/mod_traffic_mirror?path=<绝对路径>`。
3. 再发送 1 次请求。

## 预期结果

- 第 1 次请求后：`cluster_mirror` 0 命中，`skip_total{reason="sample"} >= 1`。
- reload 接口返回 200 且响应体包含 `mirror_rule.data=2.0`。
- 第 2 次请求后：`cluster_mirror` 命中 1 次，`req_labeled_total{cluster="cluster_mirror"} = 1`。
- 全程客户端 200。

## 清理

停止 `bfe` 进程、mock 后端与嵌入式 Redis。
