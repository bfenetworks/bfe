# TC-01 基本命中与复制一致性

## 用例编号与名称

TC-01 基本命中与复制一致性

## 所属场景

SC21 流量镜像（mod_traffic_mirror）

## 版本声明

- `bfe`：当前源码版本（含 `mod_traffic_mirror`）
- `bfe-access-pb`：v0.3.8（含 842-850 镜像字段，本用例不依赖）

## 测试目的

验证规则命中（`default_t()`、percentage=100）后：
1. 镜像副本与生产请求完全一致（method/path/body/model）；
2. 规则配置的敏感 Header（Authorization/Cookie/X-Api-Key）在镜像侧被剔除，生产侧保留；
3. 镜像请求被注入 `X-Bfe-Mirror: true` 与 `X-Bfe-Logid`，生产请求不带 `X-Bfe-Mirror`；
4. 主链路响应不受镜像影响；
5. Prometheus 记录 `req_labeled_total` 与 `resp_status_total`。

## 运行模式

单组件模式：真实 `bfe` + 嵌入式 Redis + mock 后端（`cluster_primary`、`cluster_mirror`）。

## 前置条件

1. `ak_mirror` 绑定无限额配额计划。
2. `ai_route.data`：`ak_mirror` → target `cluster_primary`。
3. 镜像规则：`cond=default_t()`、`mirrorCluster=cluster_mirror`、`percentage=100`、`removeHeaders=[Authorization, Cookie, X-Api-Key]`。

## BFE 请求

POST `mirror.example.org/v1/chat/completions`

| Header | 值 |
|--------|-----|
| Authorization | `Bearer ak_mirror` |
| Cookie | `session=abc123` |
| X-Api-Key | `secret-x` |
| Content-Type | `application/json` |

Body：`{"model":"gpt-4o","messages":[{"role":"user","content":"hello mirror"}]}`

## 预期结果

- 客户端返回 200，响应体为主上游答案（含 usage）。
- `cluster_primary`：命中 1 次；body 与请求一致；`Authorization=Bearer ak_mirror`；无 `X-Bfe-Mirror`。
- `cluster_mirror`：命中 1 次；body 字节与请求完全一致；`model=gpt-4o`；路径 `/v1/chat/completions`。
- `cluster_mirror` 收到的请求：`Authorization`、`Cookie`、`X-Api-Key` 均为空；`X-Bfe-Mirror=true`；`X-Bfe-Logid` 非空；`Content-Type=application/json` 保留。
- 指标（轮询等待，最长 5s）：
  - `req_labeled_total{product="ai_product",cluster="cluster_mirror",model="gpt-4o"} = 1`
  - `resp_status_total{cluster="cluster_mirror",status="200"} = 1`

## 清理

停止 `bfe` 进程、mock 后端与嵌入式 Redis。
