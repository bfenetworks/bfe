# TC-03 采样比例 0 不镜像

## 用例编号与名称

TC-03 采样比例 0 不镜像

## 所属场景

SC21 流量镜像（mod_traffic_mirror）

## 测试目的

验证 `percentage=0` 时请求全部跳过镜像，且每次跳过都计入 `skip_total{reason="sample"}`。

## 运行模式

单组件模式。

## 前置条件

镜像规则：`cond=default_t()`、`mirrorCluster=cluster_mirror`、`percentage=0`。

## BFE 请求

连续发送 5 次相同 POST `mirror.example.org/v1/chat/completions`。

## 预期结果

- 5 次请求全部返回 200。
- `cluster_mirror` 命中 0 次。
- 指标（轮询等待）：
  - `skip_total{reason="sample"} = 5`
  - `skip_sample_total = 5`
  - 无 `req_labeled_total` 记录。

## 清理

停止 `bfe` 进程、mock 后端与嵌入式 Redis。
