# TC-05 采样比例 50 统计分布

## 用例编号与名称

TC-05 采样比例 50 统计分布

## 所属场景

SC21 流量镜像（mod_traffic_mirror）

## 测试目的

验证 `percentage=50` 时按概率随机采样：镜像次数在二项分布的合理区间内（非全有/全无，非确定性轮询）。

## 运行模式

单组件模式。

## 前置条件

镜像规则：`cond=default_t()`、`mirrorCluster=cluster_mirror`、`percentage=50`。

## BFE 请求

连续发送 200 次相同 POST `mirror.example.org/v1/chat/completions`。

## 预期结果

- 全部返回 200。
- `cluster_mirror` 命中次数落在 `[60, 140]` 区间（期望 100，标准差约 7.1，容差约 ±5.6σ，将偶发失败概率压到可忽略水平；用例说明文档中明示该统计容差）。
- `skip_total{reason="sample"}` 与镜像命中数之和 = 200。

## 清理

停止 `bfe` 进程、mock 后端与嵌入式 Redis。
