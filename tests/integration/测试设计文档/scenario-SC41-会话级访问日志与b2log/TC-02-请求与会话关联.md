# TC-02 请求与会话关联

## 用例编号与名称

TC-02 请求与会话关联

## 所属场景

SC41 会话级访问日志与 b2log 封装

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证请求日志 `session_id` 与会话日志 `logid` 一致，且请求日志自身的 `logid` 独立且非 0。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程；后端为进程内 mock。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. mock 后端 `cluster_log` 已启动。
3. `bfe.conf`：`EnableAiGateway=false`，`Modules = mod_logid`、`mod_access_pb3`。
4. `mod_access_pb3.conf`：`LogPrefix=pb_access3`、`LogDir=../log`。

## 配置构造

- 加载 `mod_logid`：它为连接分配十进制 `SessionId`，请求日志与会话日志共享该值；
- 一条 HTTP 连接、一次请求后关闭连接。

## BFE 请求

| 步骤 | Host | Path | 关键设置 | 说明 |
|------|------|------|----------|------|
| 1 | log.example.org | /v1/chat/completions | 普通 HTTP GET | 单连接单请求 |

## 预期结果

- 恰好 1 条请求日志与 1 条完整（`req_num>0`）会话日志。
- `RequestLog.session_id == 会话 BfeLog.logid`，且两者非 0。
- 请求日志自身 `logid != 0`。

## 说明

- 未加载 `mod_logid` 时 `session.SessionId` 为空，请求日志与会话日志会各自生成随机兜底值，二者不相等；本用例因此固定加载 `mod_logid`。
