# TC-01 会话日志基本字段

## 用例编号与名称

TC-01 会话日志基本字段

## 所属场景

SC41 会话级访问日志与 b2log 封装

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证会话级 BfeLog 的基本字段与产品标签。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程；后端为进程内 mock。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. mock 后端 `cluster_log` 已启动。
3. `bfe.conf`：`EnableAiGateway=false`，`Modules = mod_logid`、`mod_access_pb3`；`Layer4LoadBalancer` 按用例配置。
4. `mod_access_pb3.conf`：`LogPrefix=pb_access3`、`LogDir=../log`。

## 配置构造

- Arm 1（无 VIP）：`Layer4LoadBalancer` 为空，HTTP 请求。
- Arm 2（PROXY VIP）：`Layer4LoadBalancer="PROXY"`，先发 PROXY v1 头（目的地址 127.0.0.1）再发 HTTP 请求。
- `vip_rule.data`：`ai_vip` → `127.0.0.1`。

## BFE 请求

| 步骤 | Host | Path | 关键设置 | 说明 |
|------|------|------|----------|------|
| 1 | log.example.org | /v1/chat/completions | Arm 1：普通 HTTP GET | 无 VIP |
| 2 | log.example.org | /v1/chat/completions | Arm 2：PROXY 头 + HTTP GET | VIP 映射产品 |

## 预期结果

- Arm 1：`log_type=session`、`log_tag=session_bfe`、`logid!=0`、`timestamp>0`、`proto=http`、`req_num>=1`。
- Arm 2：`log_tag=session_ai_vip`、`SessionLog.product=ai_vip`。
