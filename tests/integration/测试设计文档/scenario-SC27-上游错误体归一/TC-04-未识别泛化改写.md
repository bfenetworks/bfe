# TC-04 未识别泛化改写

## 用例编号与名称

TC-04 未识别泛化改写

## 所属场景

SC27 上游错误体归一

## 版本声明

- `bfe`：当前源码版本（含 `AIConf.NormalizeUpstreamError` 实现）

## 测试目的

验证 `UnrecognizedAction=rewrite_generic`：未识别错误体不再透传，而是被
重写为通用 `UPSTREAM_UNKNOWN` 统一错误（状态 502、type=internal_error），
满足"强制统一"场景的客户端契约。

## 运行模式

单组件模式：真实 `bfe` + 脚本化错误 mock 后端，无 Redis。

## 前置条件

1. `cluster_err` AIConf：
   `NormalizeUpstreamError={Enabled:true, UnrecognizedAction:"rewrite_generic"}`。
2. `ak_front` 无限额配额计划。

## 配置构造

```json
"NormalizeUpstreamError": {
    "Enabled": true,
    "UnrecognizedAction": "rewrite_generic"
}
```

## BFE 请求

| 步骤 | Host | Path | Authorization | Body |
|------|------|------|---------------|------|
| 1 | `front.example.org` | `/v1/chat/completions` | `Bearer ak_front` | `{"model":"deepseek-chat","messages":[{"role":"user","content":"hi"}]}` |

## 后端响应

同 TC-03（502 HTML 错误页）。

## 执行步骤

1. 启动 BFE，发送请求；
2. 解析响应状态/体与日志记录。

## 预期结果

- 响应状态码 **502**（`UPSTREAM_UNKNOWN` 映射）；
- 响应体为统一错误格式：`error.code == "UPSTREAM_UNKNOWN"`、
  `error.type == "internal_error"`、message 为泛化文案（不含上游原文）；
- `error.details.upstream_status == 502`；
- 响应头 `X-Bfe-Gw-Error: 1`；
- 访问日志：`ai_err_normalized=true` 且 `ai_err_normalize_miss=true`
  （泛化改写与 miss 标记同时成立）。

## 清理

停止 `bfe` 进程与 mock 后端，删除临时目录。
