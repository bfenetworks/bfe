# TC-02 未超阈值按基础价扣费（对照臂）

## 用例编号与名称

TC-02 未超阈值按基础价扣费（对照臂）

## 所属场景

SC15 长度分档计费与 1h 缓存写价

## 版本声明

- `bfe`：当前源码版本（2026-09-09 长度分档与 1h 缓存写价支持起）

## 测试目的

TC-01 的对照臂：输入 token 总数未超 272k 阈值时，`gpt-5.5` 仍按基础价 `PriceInputCostPerToken` / `PriceOutputCostPerToken` 计费，验证档价不影响阈值以下请求（防回归）。

## 运行模式

单组件模式：真实 `bfe` 进程 + 进程内 miniredis（计费断言）。

## 前置条件

1. mock 后端 `cluster_sc15` 返回 200 与响应体：
   `{"usage":{"prompt_tokens":100000,"completion_tokens":5000,"total_tokens":105000}}`
2. `gpt-5.5` 价格配置同 TC-01（含 272k 档价）。
3. `quota:plan_rmb` 初始配额 10000000000。

## BFE 请求

POST `http://<bfe>/v1/chat/completions`，Host `sc15.example.org`：

| 字段 | 值 |
|------|----|
| Authorization | `Bearer ak_user_a` |
| Content-Type | application/json |
| body | `{"model":"gpt-5.5"}` |

## 预期结果

1. 响应 200，`cluster_sc15` 命中 1 次。
2. 异步扣款完成后，扣费金额 =
   `CalcCostUnits(100000, 2.431e-05)`（输入基础价） +
   `CalcCostUnits(5000, 0.00014586)`（输出基础价）；
   余额 = 10000000000 - 上述金额。
