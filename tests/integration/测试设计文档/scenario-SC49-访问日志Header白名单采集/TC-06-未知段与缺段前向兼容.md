# TC-06 未知段与缺段前向兼容

## 目的

验证多段式数据文件的前向/后向兼容：未知顶层段被忽略并 Warn、不影响已知段加载；`access_header` 段缺失按空白名单运行。

## 前置条件

- 数据文件（未知段 + 已知段混排）：

```json
{
    "Version": "20261115090000",
    "access_header": {
        "req_headers": ["business_type"],
        "res_headers": []
    },
    "sampling": {"rate": 10}
}
```

- 另备缺段文件：`{"Version": "20261115100000"}`（无 `access_header`）。

## 请求构造

- 请求头携带 `Business-Type: rag`；
- 客户端 token：`ak_hdr_a`。

## 执行步骤

1. 启动 BFE（未知段文件）→ 发送请求 → 200 → 解码断言；
2. 观察 BFE 日志含未知段 `sampling` 的 Warn；
3. 热加载替换为缺段文件 → `/reload/mod_access_pb3` → 再发请求 → 解码断言。

## 预期结果

- 步骤 1：`req_headers` 含 `Business_type`——未知段不影响已知段；
- 步骤 3：reload 成功；`req_headers` 变为空（段缺失 = 空白名单），行为不退化、不报错。

## 清理

测试结束时关闭 BFE 与 mock 后端。
