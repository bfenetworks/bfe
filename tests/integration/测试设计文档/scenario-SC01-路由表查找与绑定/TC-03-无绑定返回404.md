# TC-03 无绑定返回 404

## 用例编号与名称

TC-03 无绑定返回 404

## 所属场景

SC01 路由表查找与绑定

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证未在 `ApikeyRouteTableBindings` 中绑定的 API-Key，BFE 返回 404 且不转发到任何后端。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. mock 后端已启动，所有 cluster 默认返回 200。
3. 临时 BFE 配置已生成并加载。

## 配置构造

- `ApikeyRouteTableBindings` 中不包含 `ak_no_binding`。

## BFE 请求

| 字段 | 值 |
|------|-----|
| Host | `api.example.org` |
| Path | `/v1/chat/completions` |
| Authorization | `Bearer ak_no_binding` |
| Body | `{}` |

## 预期结果

- 响应状态码：404
- 响应体包含 `AI route not found`
- 所有 mock 后端命中次数均为 0

## 清理

停止 `bfe` 进程与所有 mock 后端，删除临时目录。
