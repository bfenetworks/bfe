# TC-01 命中请求零决策服务调用

## 用例编号与名称

TC-01 命中请求零决策服务调用

## 所属场景

SC25 缓存查找前移

## 版本声明

- `bfe`：当前源码版本（缓存查找已前移至 `HandleFoundProduct`，含 `mod_ai_intent`）

## 测试目的

验证懒解析下沉的核心收益：缓存命中短路发生在路由规则求值（`req_ai_intent_in`
懒解析触发点）之前，命中请求不再调用决策服务。

## 运行模式

单组件模式：真实 `bfe` + 嵌入式 Redis + mock 决策服务 + `cluster_flash` / `cluster_kimi` mock 后端。

## 前置条件

1. 已编译 `bfe` 可执行文件，嵌入式 Redis 已启动。
2. mock 决策服务已启动，`Calls()=0`；路由表 `apikey_ak_front` 含
   `req_ai_intent_in("task_type", "test_writing", 0.9)` 规则（`cluster_flash`）。
3. 缓存规则：`default_t()` + `cacheKeyStrategy=lastQuestion`、`cacheTTL=3600`。
4. `ak_front` 绑定无限额配额计划。

## 配置构造

- 缓存规则：

```json
{
    "cond": "default_t()",
    "cacheKeyStrategy": "lastQuestion",
    "cacheTTL": 3600,
    "maxBodyBytes": 1048576,
    "maxValueBytes": 1048576
}
```

## BFE 请求

发送 2 次相同 POST 请求：

| 步骤 | Host | Path | Authorization | Body |
|------|------|------|---------------|------|
| 1 | `front.example.org` | `/v1/chat/completions` | `Bearer ak_front` | `{"model":"deepseek-chat","messages":[{"role":"user","content":"帮我给这个函数写单元测试"}]}` |
| 2 | `front.example.org` | `/v1/chat/completions` | `Bearer ak_front` | 同上 |

## 预期结果

- 第 1 次请求：miss。
  - mock 决策服务 `Calls() == 1`（路由规则引用意图原语，懒解析在规则求值时触发一次）；
  - `cluster_flash` `Hits() == 1`（test_writing@0.93 ≥ 0.9，命中 intent-flash）；
  - 响应 200，答案为 `from cluster_flash`；
  - Redis 出现缓存键（轮询等待，最长 5s）。
- 第 2 次请求：**hit**。
  - mock 决策服务 `Calls()` **仍为 1**（不增——命中短路在路由求值之前，懒解析未触发）；
  - `cluster_flash` `Hits()` **仍为 1**（上游零调用）；
  - 响应头 `X-Bfe-Ai-Cache: hit`，响应体为缓存答案；
  - 响应 200。

> 对照基线：旧行为（查找在 `HandleAfterLocation`）下第 2 次请求决策服务
> `Calls()` 会变为 2——本用例的 `== 1` 断言直接锁定前移生效。

## 清理

停止 `bfe` 进程、mock 后端、mock 决策服务与嵌入式 Redis，删除临时目录。
