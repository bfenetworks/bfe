# TC-02 未命中路径意图路由不变

## 用例编号与名称

TC-02 未命中路径意图路由不变

## 所属场景

SC25 缓存查找前移

## 版本声明

- `bfe`：当前源码版本（缓存查找已前移至 `HandleFoundProduct`，含 `mod_ai_intent`）

## 测试目的

对照回归：缓存查找前移后，**未命中**路径的懒解析时机与意图路由语义必须与
前移前完全一致（每次 miss 都正常分类、按规则分流），防止前移误伤主链路。

## 运行模式

单组件模式：真实 `bfe` + 嵌入式 Redis + mock 决策服务 + `cluster_flash` / `cluster_kimi` mock 后端。

## 前置条件

1. 已编译 `bfe` 可执行文件，嵌入式 Redis 已启动。
2. mock 决策服务已启动，`Calls()=0`。
3. 路由表 `apikey_ak_front`：intent-flash（test_writing@0.9 → `cluster_flash`）、
   intent-default（`cluster_kimi`）。
4. 缓存规则：`default_t()` + `lastQuestion`（与 TC-01 相同）。

## BFE 请求

依次发送 2 个**不同问题**的 POST 请求（互不命中缓存）：

| 步骤 | Host | Path | Authorization | Body |
|------|------|------|---------------|------|
| 1 | `front.example.org` | `/v1/chat/completions` | `Bearer ak_front` | `{"model":"deepseek-chat","messages":[{"role":"user","content":"帮我给这个函数写单元测试"}]}` |
| 2 | `front.example.org` | `/v1/chat/completions` | `Bearer ak_front` | `{"model":"deepseek-chat","messages":[{"role":"user","content":"写文档：补充这个模块的 README"}]}` |

## 预期结果

- 第 1 次请求：miss → 决策服务 `Calls() == 1`；`cluster_flash` `Hits() == 1`
  （test_writing@0.93 命中 intent-flash）；响应 200，答案 `from cluster_flash`。
- 第 2 次请求：miss（问题不同）→ 决策服务 `Calls() == 2`；
  `cluster_kimi` `Hits() == 1`（doc_writing 无专属规则，走 intent-default）；
  响应 200，答案 `from cluster_kimi`。
- 两次请求响应头均无 `X-Bfe-Ai-Cache: hit`（均为 miss）。

## 清理

停止 `bfe` 进程、mock 后端、mock 决策服务与嵌入式 Redis，删除临时目录。
