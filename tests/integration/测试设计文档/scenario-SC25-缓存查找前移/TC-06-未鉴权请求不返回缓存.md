# TC-06 未鉴权请求不返回缓存

## 用例编号与名称

TC-06 未鉴权请求不返回缓存

## 所属场景

SC25 缓存查找前移

## 版本声明

- `bfe`：当前源码版本（缓存查找已前移至 `HandleFoundProduct`；注册序：
  `mod_ai_token_auth` → `mod_ai_cache` → `mod_ai_route`）

## 测试目的

安全回归：缓存查找注册在 `mod_ai_token_auth` **之后**——未鉴权请求即使问题
已被缓存，也绝不能拿到缓存答案。

## 运行模式

单组件模式：真实 `bfe` + 嵌入式 Redis + mock 决策服务 + mock 后端。

## 前置条件

1. 已编译 `bfe` 可执行文件，嵌入式 Redis 已启动。
2. 已有一个缓存问题：先用 `Bearer ak_front` 正常请求 1 次（miss 回写缓存，
   决策服务 `Calls()==1`，`cluster_flash` `Hits()==1`）。

## BFE 请求

| 步骤 | Host | Path | Authorization | Body |
|------|------|------|---------------|------|
| 1 | `front.example.org` | `/v1/chat/completions` | **无**（或 `Bearer ak_invalid`） | 同前置步骤的问题 |

## 预期结果

- 请求被 `mod_ai_token_auth` 拒绝（401/403，按 token 规则口径）。
- 响应**不含**缓存答案，无 `X-Bfe-Ai-Cache: hit` 响应头。
- mock 决策服务 `Calls()` 仍为 1（鉴权在缓存查找之前，懒解析未被触发）。
- `cluster_flash` `Hits()` 仍为 1。
- Redis 中缓存键不受影响。

## 清理

停止 `bfe` 进程、mock 后端、mock 决策服务与嵌入式 Redis，删除临时目录。
