# SC42 缺价动作与形态信号（issue #1479）

## 1. 场景背景与目的

模型按"模型 + 接口类型（mode）"分别定价。此前 issue #1408 已让"非 chat mode 缺价"回退 chat 价计费并打 `ai_price_miss`，但缺价的**处置不可配置**（无法拒单）、**信号不可直读**（bool 不区分形态）、**子项缺价不可见**。

本场景验证 issue #1479 的完整行为：`AIConf.PriceMissAction` 三态（`fallback_chat` / `bill_zero` / `reject`）、四层缺价信号（结构化 `PRICE_MISS` 日志、计数器、`ai_price_miss`、`ai_price_warn`）以及"回退子项缺价"的接受残余口径。

## 2. 运行模式

- 单组件模式：真实 `bfe` 进程 + 内存 Redis；
- 静态 AIConf（由 `BFEConfigBuilder` 生成 `cluster_conf.data`）：4 个集群只配 **chat** 价，请求走 `/v1/responses`（mode=responses）以命中缺价路径；
- 加载 `mod_ai_route` / `mod_ai_token_auth` / `mod_body_process` / `mod_access_pb3`（pb 日志断言）；
- mock 后端：fallback/billzero/reject 三臂返回普通 usage；subitem 臂返回带 cache token 的 usage。

## 3. 测试集群

| 集群 | Host | PriceMissAction | 价格表 | 用途 |
|---|---|---|---|---|
| `cluster_price_fallback` | `price-fallback.example.org` | `fallback_chat` | 仅 chat 价（含 cache 键为零值写法） | 回退计费臂 |
| `cluster_price_billzero` | `price-billzero.example.org` | `bill_zero` | 仅 chat 价 | 按 0 臂 |
| `cluster_price_reject` | `price-reject.example.org` | `reject` | 仅 chat 价 | 拒单臂 |
| `cluster_price_subitem` | `price-subitem.example.org` | `fallback_chat` | 仅 chat 价、**无 cache 子项键** | 子项缺失臂 |

价格：input 0.000003 元/token（300 固定单位）、output 0.000009 元/token（900 固定单位）。

## 4. 测试例

| 用例 | 验证点 |
|---|---|
| TC-01 | `fallback_chat`：responses 请求按 chat 价计费；pb `ai_price_miss=true` + `ai_price_warn=fallback`；`PriceFallbackUsed` +1 |
| TC-02 | `bill_zero`：请求成功但扣费 0；pb `ai_price_warn=no_entry` + `ai_cost_value=0` + `ai_zero_cost_reason=price_miss` |
| TC-03 | `reject`：**转发前**拒绝（后端 hits=0）、503 + `error.code=PRICE_NOT_CONFIGURED`、余额不变；非 2xx 行仍带 `ai_price_miss` + `ai_price_warn=reject`（issue #1479 方案 A）；`PriceRejected` +1 |
| TC-04 | 接受残余：回退条目缺 cache 子项键且请求用了 cache → 仍 200、按 chat 价计费（cache 维度按 0）、`ai_price_warn=subitem_missing`、`PriceFallbackSubItemMiss` +1；**不拒单** |

## 5. 关键实现细节

- reject 判定挂在 `HandleAfterAITargetModel`（`targetModelCheckFilter`）：`HandleFoundProduct` 阶段 `Route.ClusterName` 尚未设置，无法定位集群价格表；该回调正是"target model 已解析、尚未转发"的钩子；
- `reject` 返回 `BfeHandlerResponse`（自定长 503 body，连接可复用，issue #1416 口径）；
- `ai_price_warn` 取最具体形态：`subitem_missing > fallback > no_entry/no_baseline/no_model_table`，`reject` 互斥；
- 计数器经 monitor 端口读取（`common.ModuleMetric` / `WaitForModuleMetric`），pb 断言在 BFE 停止后解析访问日志。
