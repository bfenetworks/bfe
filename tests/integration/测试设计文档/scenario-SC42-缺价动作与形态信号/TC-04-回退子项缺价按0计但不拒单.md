# TC-04 回退子项缺价按 0 计但不拒单

## 目的
验证"接受残余"决策：回退借用的 chat 条目缺本请求实际用到的 cache 子项价格键时，该维度按 0 计（少收），只发信号、**不拒单**。

## 步骤
1. 集群 `cluster_price_subitem`（`fallback_chat`，chat 条目无 cache 子项键）；
2. mock 后端返回带 cache token 的 usage（`cache_read_tokens=40`、`cache_write_tokens=10`）；
3. 断言响应、扣费、计数器、pb。

## 预期
- 200（不拒绝）；后端 hits=1；
- 扣费非 0（chat 价生效，cache 维度按 0）；
- `PriceFallbackSubItemMiss`=1；
- pb：`ai_price_warn=subitem_missing`（最具体形态覆盖 `fallback`）、`ai_price_miss=true`。
