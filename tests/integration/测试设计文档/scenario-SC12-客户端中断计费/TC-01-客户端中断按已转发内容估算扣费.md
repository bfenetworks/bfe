# TC-01 客户端中断按已转发内容估算扣费

## 目的

验证 issue #1478：EstimateToken = true 时，客户端在流式输出途中断开（TCP RST）且未拿到最终 usage，BFE 按**已转发内容**估算计费——鉴权期按请求体播种的输入 token + 已从上游读取并进入转发路径的每个内容帧的 token 估算；后端未生成/未交付的部分不计费（保留 issue #1352 的实质）。

对应实现：`TestTC01_ClientAbortBilledByForwardedContent`（`scenario-SC12-client-abort-billing/sc12_client_abort_billing_test.go`）。

## 前置条件

- BFE 已启动并加载 `cluster_client_abort`，`EstimateToken = true`、`mod_body_process` 已加载且产品规则匹配（逐 chunk 估算累加依赖它）。
- Redis 中 `quota:plan_rmb` 余额预置为 `10000000000`。
- mock 后端进入 SSE 模式：**先发送不含 usage 的帧**（`ping` + 一个内容帧）后阻塞在 `SSEHold` 上。

## 请求构造

| 字段 | 值 |
|------|-----|
| Method | `POST` |
| Host | `abort-billing.example.org` |
| Path | `/anthropic/v1/messages` |
| Header | `Authorization: Bearer ak_user_a` |
| Header | `anthropic-version: 2023-06-01` |
| Body | `{"model":"claude-opus-4-6","stream":true,"max_tokens":1024}` |

## 后端响应（SSE）

```
data: {"type":"ping"}

data: {"type":"content_block_delta","index":0,"delta":{"type":"text_delta","text":"hello"}}

（阻塞，直至客户端中断）
```

说明：

- 帧序列刻意**不含任何 usage 事件**，使计费完全走"已转发内容估算"路径（带 `message_start.usage` 的形态按观测值计费，见 TC-02 的补充说明）。
- 中断由 SSE 响应的 `cancelOnClientClose` 机制感知：客户端 RST 后 CloseWatcher 关闭上游 body，`copyResponse` 收到读错误并按客户端中断归因（`ErrClientWrite`），无需依赖后端追加数据。
- 关闭上游 body 会让 issue #1474 的 `streamTruncationInjector` 观察到"读错误"，从而向客户端流补发一个协议错误事件帧（OpenAI 原生 envelope）。该帧进入同一读取路径并被估算器计入（132 字节 / 4 = 33 token）——与 bfe SC29 TC-07/08 的口径一致，本用例的期望金额显式预算了它。

## 执行步骤

1. 启动 BFE、mock 后端与内存 Redis，预置余额。
2. 客户端通过裸 TCP 发送请求，读取 SSE 数据直至收到 `ping` 与内容帧。
3. 客户端设置 `SO_LINGER=0` 后关闭连接（发送 TCP RST）；CloseWatcher 关闭上游 body，请求按客户端中断收尾。
4. 等待请求结束，读取 Redis 余额与 `mod_ai_token_auth` 计数器并断言。

## 预期结果

- HTTP 响应状态码 200（SSE 响应头先于中断发送）。
- **按已转发内容扣费**（逐事件整数除法）：
  - `promptEst = len(请求体) / 4`（鉴权期播种）
  - `completionEst = len(ping 帧)/4 + len(内容帧)/4 + len(注入错误事件帧)/4 = 3 + 21 + 33 = 57`
  - `remaining = 10000000000 − (14 × 452 + 57 × 2262) = 9999864738`
- 计数器：`AbortBillingEstimated` +1；`AbortBillingSkipped` 不变；`BillingZeroCost` 不变（本请求已计费）；`UsageUnrecognized` 不变。
- 行级 `ai_usage_source=aborted` 由单元测试覆盖（本场景未加载 `mod_access_pb3`，字段口径另见 SC05 场景）。
- 修复前行为：该形态零扣费（issue #1352 时期的"客户端中断一律不扣费"）。

## 与其他用例的关系

- TC-04 是与之互补的**零扣费臂**（`EstimateToken = false`）；
- TC-02（已拿到最终 usage 后中断）不受本用例影响，仍按实际 usage 计费；
- 上游中途断流的同类口径见 bfe SC29 TC-07（issue #1474）。

## 清理

- 停止 BFE、关闭 mock 后端与 Redis。
