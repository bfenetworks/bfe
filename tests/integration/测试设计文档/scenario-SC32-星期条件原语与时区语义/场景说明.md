# SC32 星期条件原语与时区语义

## 1. 场景背景与目的

条件原语新增 `time_weekday_in(weekday_list, zone)`：判断当前时间所在的星期是否属于给定集合
（`0`=周日、`1`=周一、…、`6`=周六，与 Go `time.Weekday` 及 cluster 分时段计价的 `weekdays` 约定一致）。
`zone` 为单个军事时区字母（见 `bfe_util.TimeZoneMap`），可省略，省略时按 **`Z`（UTC）** 判定。

本场景验证该原语作为**路由条件**时的实际判定结果与边界语义：

- **星期编号语义**：`0`=周日、`6`=周六 的编号与区间是否正确（最易错点：编号整体错位）；
- **集合判定**：`1|2|3|4|5`、`6`、`0` 等集合的命中与未命中；
- **时区参与判定**：同一时刻在 `"H"`（UTC+8）与省略（UTC）下分属不同星期，路由结果不同；
- **未命中回落**：条件不命中时按路由表规则顺序回落到后续规则；
- **真实时钟路径**：不带 `X-Bfe-Debug-Time` 时按进程系统时间判定（非仅调试头路径）；
- **非法参数 fail-fast**：非法星期、非法时区字母、参数类型错误导致配置加载失败并给出可定位的错误信息。

## 2. 运行模式

- **单组件模式**：仅启动真实 `bfe` 进程。
- 不涉及 `ai-gateway-api` 与 `conf-agent`。

## 4. 路由表设计

### 4.1 apikey_ak_user_a（apikey 级别，唯一路由表）

按顺序匹配，命中即返回；两个 Host 分别承载「显式 `"H"` 时区」与「省略 zone（UTC）」两臂。

#### 4.1.1 Host `weekday.example.org`（显式 `"H"`，UTC+8）

| 规则名 | 条件 | targets |
|--------|------|---------|
| `weekday-work` | `req_host_in("weekday.example.org") && time_weekday_in("1\|2\|3\|4\|5", "H")` | `cluster_weekday_work`（weight 100） |
| `weekday-sat` | `req_host_in("weekday.example.org") && time_weekday_in("6", "H")` | `cluster_weekday_sat`（weight 100） |
| `weekday-sun` | `req_host_in("weekday.example.org") && time_weekday_in("0", "H")` | `cluster_weekday_sun`（weight 100） |

三条规则按星期集合**互斥且穷尽**（`{1..5}` ∪ `{6}` ∪ `{0}` = 一周七天），因此每个请求必然命中且只命中一条：
命中哪个 cluster 即直接反映原语的判定结果，编号错位会表现为「命中错误 cluster」而不是笼统的回落。

#### 4.1.2 Host `weekday-utc.example.org`（省略 zone，按 UTC）

| 规则名 | 条件 | targets |
|--------|------|---------|
| `weekday-utc-work` | `req_host_in("weekday-utc.example.org") && time_weekday_in("1\|2\|3\|4\|5")` | `cluster_weekday_utc_work`（weight 100） |
| `weekday-utc-default` | `req_host_in("weekday-utc.example.org")`（无条件） | `cluster_weekday_utc_default`（weight 100） |

该 Host 的 work 规则**不穷尽**（周日及其他星期都会不命中），用于验证：
① 省略 zone 时按 UTC 判定；② 条件不命中时按规则顺序回落到后续（无条件下）规则。

## 5. 测试例列表

| 编号 | 名称 | 核心验证点 |
|------|------|------------|
| TC-01 | 星期编号语义与集合命中 | 用 `X-Bfe-Debug-Time` 遍历周一到周日 7 个时刻，断言分别命中 `work`/`sat`/`sun` 分支（锁定 `0`=周日、`6`=周六）；追加不带调试头的真实时钟臂 |
| TC-02 | 时区语义与缺省 UTC | 同一时刻（北京周一 00:00 = UTC 周日 16:00）在 `"H"` 臂命中 `cluster_weekday_work`、在 UTC 臂不命中并回落 `cluster_weekday_utc_default`；对照时刻（两臂同为周二）两臂均命中 work |
| TC-03 | 非法参数配置加载失败 | 非法星期 `"7"`、非法时区 `"QQ"`、参数类型错误 `time_weekday_in(0)` 均导致 BFE 启动失败，日志含规则原文与具体错误 |

优先级：均为 P0（TC-03 为 P1）。
